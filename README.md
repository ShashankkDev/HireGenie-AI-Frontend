📌 Overview

HireGenie AI is a full-stack web application that generates personalized interview preparation reports using a user's resume and target job description. It leverages AI to automate preparation and reduce manual effort by up to 40%.

✨ Features
📄 Resume Parsing (PDF Supported)
Automatically extracts and processes resume content.
🤖 AI-Based Interview Preparation
Integrated Google Gemini API to generate role-specific interview plans.
📊 Dynamic Report Generation
Get structured reports including:
Key skills to focus on
Expected interview questions
Personalized improvement suggestions
🔐 Authentication & Security
JWT-based authentication system for secure access.
⚡ Scalable Backend
REST APIs handling 100+ requests/day with optimized performance.
📱 Responsive UI
Clean and accessible interface across devices.
🛠️ Tech Stack
Category	Technology
Frontend	React.js
Backend	Node.js, Express.js
Database	MongoDB
AI Service	Google Gemini API
Deployment	Vercel
⚙️ How It Works
Upload your resume (PDF)
Paste the job description
AI analyzes both inputs
Generates a custom interview preparation report


🚀 Installation & Setup
# Clone the repository
git clone https://github.com/your-username/hiregenie-ai.git

# Navigate into the project
cd hiregenie-ai

# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd ../server
npm install

# Start backend server
npm run dev

# Start frontend
cd ../client
npm start
🔐 Environment Variables

Create a .env file in the server folder and add:

GEMINI_API_KEY=your_api_key
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
